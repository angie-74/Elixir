SDL3 constants (src/window/sdl3_compat)
---------------------------------------

- src/window/sdl3_compat/SDL3/SDL_scancode.h, SDL_keycode.h,
  SDL_mouse.h and SDL_gamepad.h are Elixir's own headers (Apache-2.0).
  They reproduce only the names and numeric values of the SDL3 public
  constants that Mocktail's portable input code uses: scancodes (the USB HID
  Keyboard/Keypad usage IDs), keycodes and key modifiers, mouse buttons, and
  gamepad buttons and axes. That code therefore builds unchanged on Windows.
  The headers declare no functions and contain no SDL code or documentation
  text.
- SDL is distributed under the zlib license. Elixir's Windows build does not
  use or link SDL, so no SDL source or license file is part of this
  repository.
